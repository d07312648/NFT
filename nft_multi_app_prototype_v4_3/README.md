# NFT Journey Lab v3

暗号資産取引所、ウォレット、NFTチケット購入サイトを別々のサービスとして再現した、研究用の静的Webプロトタイプです。

## 起動方法

ZIPを解凍し、`index.html` をChrome、Edge、Safariなどで開いてください。サーバーや追加インストールは不要です。

## 再現する流れ

1. NOVA Exchangeでアカウント作成・疑似本人確認
2. 価格変動する販売所UIでETHを購入
3. Orbit Walletを作成し、復旧用フレーズを確認
4. Orbit Walletの公開鍵をコピー
5. NOVA Exchangeの送金画面へ戻る
6. コピーした公開鍵を貼り付け、ETHを送金
7. Orbit Walletで着金を確認
8. MintGateへOrbit Walletを接続
9. 接続確認用メッセージへ署名
10. 5種類のNFTチケットから選択
11. 価格・ガス代（手数料）・コントラクトを確認
12. 購入トランザクションへ署名
13. ネットワーク承認後、NFTをウォレットへ追加

## 研究用ログ

完了画面の「結果をJSONで保存」から、次を取得できます。

- 総所要時間
- サービス切替回数
- 公開鍵コピー回数
- 貼り付け回数
- 署名回数
- 入力エラー回数
- 各サービスの滞在時間
- ETH購入レート、購入量
- 送金量
- 選択したチケット
- 操作イベントログ

## 重要

- 実際の暗号資産、NFT、ウォレット、秘密鍵は生成されません。
- 表示される価格は外部APIではなく、研究用に疑似変動させています。
- `file://` で開いた際にブラウザがクリップボードAPIを制限する場合、従来方式のコピー処理へ自動的に切り替えます。

## v5.0 PassMarket（暗号資産で売買するNFTマーケットプレイス）

OpenSeaのような二次流通の仕組みを、ETHで体験できるマーケットプレイスを追加しました。画面上部（スマートフォンでは下部ナビ）の「マーケット」から開けます。デザイン・画面構成は簡素化版（日本円版）のPassMarketと同じで、通貨と手続きだけを暗号資産の流れに合わせています。

### ウォレット接続
- PassMarketを使うには、Orbit Walletを接続してメッセージへ署名（ガス代なし）。複数ウォレットがある場合は選択
- 出品・売却・購入は接続中のウォレットで行い、NFTを保有している別のウォレットの操作時はそのウォレットへの接続を求める

### 出品・売却
- Orbit Walletの保有NFT、またはPassMarketのマイページから、自分でETHの価格を決めて出品（日本円の目安も表示）
- 初めて出品するコレクションでは、PassMarketにNFTの移動を許可する「コレクションの承認」トランザクション（ガス代 約0.0012 ETH）に署名。その後、出品内容へメッセージ署名（ガス代なし）
- 価格に応じて自動で売却をシミュレーション
  - 売れやすい価格帯の中：約12〜45秒で他のユーザーが購入（安いほど早く売れる）
  - 相場より安い：約10秒以内に売れる（確認チェックが必要）
  - 相場より高い：すぐには売れず、25〜40秒後に購入希望者からオファーが届く
- 価格変更はメッセージ署名（ガス代なし）、出品の取り消し（約0.0009 ETH）とオファーの承諾（約0.0016 ETH）はトランザクション署名とガス代が必要
- 公式NFTチケットは定価（ETH）が上限（`TICKET_RESALE_CAP_RATIO` で変更可）。出品中のチケットは入館に使用不可

### 売上・送金
- 売上は「販売価格 − マーケット手数料2.5% − クリエイター収益」のETHが、NFTを保有していたウォレットへ直接入金
- 「売上・送金」ページで、NOVA ExchangeのETH入金アドレスを登録して取引所へ送金（ガス代 約0.0006 ETH）。着金すると取引所のETH残高に反映
- ETHの入出金履歴（売上・購入・ガス代・オファー確保・送金）を一覧表示

### 購入・オファー
- 他のユーザーの出品を、接続中ウォレットのETHで購入。チェックアウト → トランザクション署名（NFT価格＋ガス代 約0.0028 ETH）→ ネットワーク承認 → ウォレットへ追加
- 購入したNFTはOrbit Walletに表示され、再び出品・売却できる（チケットは入館・ゲーム特典もそのまま利用可能）
- ウォレットのETHを確保してオファーを送信（メッセージ署名、ガス代なし）。出品価格の90%以上で承諾されやすく、不成立ならウォレットに戻る

### マーケット機能・NFTの種類
- 探す、ランキング、アクティビティ（他ユーザーの取引がリアルタイムに発生）、マイページ、検索、お知らせ、コレクション・アイテムページ、30日の価格推移グラフ
- 既存の6種類のNFTチケットに加え、8つのコレクション（アバター、アート3種、トレカ、御朱印、音楽、会員権）を追加。`nft-art.js` がシード値から1点ずつ異なるアートを生成（ゲームは付きません）

### 研究用ログ
- 署名回数（`signature_count`）にPassMarketでの接続・出品・購入などの署名も加算
- 結果JSONに `passmarket`（売却・購入・出品・オファー・取引所への送金・ガス代の記録）を追加

### ファイル構成
- `marketplace.js`：PassMarketの取引ロジックと画面（ETH版）
- `nft-art.js`：コレクティブルNFTのアート生成（簡素化版と共通）

## v5.2 ガイドと入力欄の改善

- 金額の入力欄を日本語入力（全角数字・変換中の入力）に対応：PassMarketの出品価格・オファー金額・取引所への送金額、取引所のETH購入額・ETH売却数量
- マーケットを初めて開いたときに、画面の該当箇所をハイライトしながら6ステップの説明を表示（スキップ不可。最後の「はじめる」で閉じる）
  1. 二次流通：運営元が二次流通を認めている場合、NFTをマーケットプレイスで売買できること
  2. 運営への還元：公認の二次流通では運営にも手数料が入ること（従来サービスとNFTの手数料の流れの図付き）
  3. 使用後も残る価値：アート・長期特典・サインなどの付加価値があれば、使用後も売買される可能性があること
  4. NFTだからできること：所有者と取引履歴を記録し、真正性を証明できるNFTだから実現できること
  5. さまざまなジャンル：チケット以外にアート、ゲームで使えるキャラクター、観光の記念品などがあること
  6. 体験してみましょう：購入済みのチケットの売却やNFTの購入を促す
- マーケットの「探す」下部の「はじめてガイドを見る」から、いつでも再表示可能
- 購入完了ガイドの「NFTの説明へ進む」の下に「閉じる」を追加
- 購入完了ガイドの表示後は、保有NFTページの「NFTの詳しい説明を読む」から、NFTの特徴と注意点（4つのポイント）をいつでも読めるように変更
- スマートフォンでMintGateの「ウォレットでNFTを見る」などからウォレットを開いた直後に購入完了ガイドが表示されると、ハイライトしたカードが画面外になる問題を修正（画面のスクロールが止まってから位置を合わせる）
- 研究用ログに、マーケットのガイド（`trade_guide_started`／`trade_guide_step_viewed`／`trade_guide_completed`）と、NFTの詳しい説明の表示（`nft_explanation_opened`／`nft_explanation_closed`）を追加。購入完了ガイドを「閉じる」で終えた場合は `nft_ownership_guide_completed` の `step` が1になる
- 簡素化版（日本円版）と同じ「運営への還元」の図（`assets/guide/resale-fee-diagram.png`）を追加
